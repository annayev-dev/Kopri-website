# Köpri — Витрина веб‑сайта (русский)

Коротко: Этот репозиторий содержит одностраничный маркетинговый сайт для мобильного приложения Köpri. Это лёгкая одностраничная страница с анимацией и подбором шрифтов (index.html).

---

Типографика: Manrope & JetBrains Mono · Тёмная/светлая тема · Богатые CSS‑анимации

## Краткое содержание

index.html в репозитории содержит:

- Эффектный hero‑блок (градиентные заголовки, CTA‑кнопки)
- Демонстрация телефона (перспектива, свечение, плавающие «чипы»)
- Preloader, «blob»‑формы, анимации float и pulse
- Поддержка тёмной/светлой темы через `html[data-theme]`
- Шрифты подключены с CDN: Manrope (несколько весов) и JetBrains Mono

---

## Визуалы и типографика

- Шрифты подключены в head через @fontsource CDN для Manrope и JetBrains Mono.
- Для наглядности добавьте GIF‑демо или скриншоты в `assets/` (например `assets/demo.gif`, `assets/screenshot-hero.png`) и вставьте в README.

## Анимации (кратко)

- Preloader с пульсирующим логотипом и движущейся полосой загрузки
- Blob‑формы: мягкие размытые объекты на фоне
- Плавающие «чипы»: информационные бейджи вокруг макета телефона
- Эффект блеска на CTA: скошенный белый градиент, проходящий по кнопке
- Marquee: автоматически прокручиваемая полоса текста (остана��ливается при hover)

Примечание: большие blur‑эффекты и тяжёлые box‑shadow могут быть затратными на мобильных устройствах — рассмотрите их уменьшение.

## Локальный предпросмотр

1. Клонируйте репозиторий:

   git clone https://github.com/annayev-dev/Kopri-website.git
   cd Kopri-website

2. Запустите простой статический сервер:

   # Python 3
   python -m http.server 8000

   # или
   npx serve .

3. Откройте http://localhost:8000/index.html

---

## Советы по настройке

- Меняйте цвета темы через CSS‑переменные в `:root` (например `--accent`, `--bg`).
- Заменяйте шрифты, редактируя ссылки в head.
- Для доступности добавьте `prefers-reduced-motion`.
- Для модульности вынесите CSS в `styles.css`, JS в `app.js`.

---

## Структура файлов (кратко)

- `index.html` — одна страница с CSS и небольшим JS
- `assets/` — изображения, иконки и демо‑GIFы
